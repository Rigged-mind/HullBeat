# Кольори

Базовий тон — **#14403A**, глибокий синьо-зелений (hue ≈ 172°, sat ≈ 52%).
Похідне від [../docs/ui-spec.md](../docs/ui-spec.md), п.1 (умови експлуатації).

Файли: `Color.kt` (Compose, джерело істини), `colors.xml` (XML-фолбек для
нотифікацій і віджетів).

## Три схеми, а не дві

| Схема | Коли | Чим відрізняється |
|---|---|---|
| **Light** | за замовчуванням, системна | звичайний контраст, м'які поверхні |
| **Dark** | системна темна, моторний відсік | інверсія, приглушені поверхні |
| **Sunlight** | ручний перемикач «Яскраве сонце» | чистий білий фон, майже чорний текст, контраст ≥ 7:1, межі 2dp |

Sunlight — **не просто «світла тема з жирнішим шрифтом»**. На палубі опівдні
екран втрачає близько половини сприйнятого контрасту, тому м'які сірі
(`onSurfaceMuted`) там зникають повністю. У цій схемі приглушений текст
підтягується до основного, а декоративні розділювачі замінюються на справжні межі.

## ⚠️ Чому «все гаразд» — сірий, а не зелений

Бренд у нас зелений. Якби зелений означав ще й «все гаразд», користувач не відрізняв би
статусну позначку від звичайного оформлення — кнопки, заголовка, іконки вкладки.
Тому шкала статусів **червоний → бурштиновий → нейтральний сірий**, і зелений
лишається виключно за брендом.

Побічний виграш: людям із дейтеранопією (≈6% чоловіків, а це наша аудиторія)
пара «червоний/зелений» найважча. Пара «червоний / бурштиновий / сірий»
розрізняється ще й за світлотою.

## Три правила застосування

**1. Колір ніколи не єдиний носій сенсу.** Кожна статусна позначка супроводжується
текстом («прострочено», «за 3 мотогодини») **і** формою:

```
●  заповнене коло   прострочено
◐  напівзаповнене   настає
○  порожнє          далі
```

Це працює і в сонці, де кольори вигоряють, і при друку PDF у ч/б.

**2. Первинна дія завжди `primary` на всю ширину, внизу.** Другорядні — текстові,
без заливки. Третьої за важливістю кнопки на екрані не буває.

**3. Небезпечні дії не червоні за замовчуванням.** `statusOverdue` зайнятий станом
обслуговування. Для «Видалити все» — окремий `danger` у тому ж червоному, але
тільки в підтверджувальних діалогах і в розділі «Небезпечна зона».

Порахував `tools/check_contrast.py`. Текст — потрібно 4.5:1, елементи інтерфейсу
й межі — 3:1, схема Sunlight — 7:1.

| Пара | Ratio | Потрібно |
|---|---|---|
| Light: текст на surface | 17.12 | 4.5 ✓ |
| Light: приглушений текст | 6.82 | 4.5 ✓ |
| Light: білий на primary | 11.51 | 4.5 ✓ |
| Light: prostrочено на surface | 6.54 | 4.5 ✓ |
| Light: настає на surface | 6.39 | 4.5 ✓ |
| Light: outline на surface | 3.86 | 3.0 ✓ |
| Dark: текст на surface | 14.92 | 4.5 ✓ |
| Dark: primary-кнопка (текст на заливці) | 6.80 | 4.5 ✓ |
| Dark: прострочено на surface | 7.79 | 4.5 ✓ |
| Dark: outline на surface | 3.42 | 3.0 ✓ |
| Sunlight: текст на surface | 19.12 | 7.0 ✓ |
| Sunlight: білий на primary | 14.57 | 7.0 ✓ |
| Sunlight: прострочено на surface | 9.11 | 7.0 ✓ |

Перші два кандидати на `outline` (#8FA5A0 / #43544F) провалились на 2.61 і 2.22 —
замінені. **Будь-яка зміна палітри проганяється через скрипт заново.**

## ⚠️ Одне застереження про схожість

У Bavyn — нашого найближчого конкурента за позиціюванням — фірмовий колір теж
темний бірюзовий, приблизно `#15586B` ([../docs/competitor-ux.md](../docs/competitor-ux.md)).
Наш зеленіший і темніший, тож поруч вони розрізняються, але сімейство одне.

Це не привід міняти колір — у морській ніші синьо-зелений є в половини застосунків.
Але **іконку застосунку варто будувати не на кольорі, а на формі**: у сторі
поруч стоятимуть кілька темно-бірюзових плиток, і виграє та, що має впізнаваний силует.

## Кольори: одне джерело

`design/palette.json` — **єдине джерело всіх кольорів HullBeat.** Правити там,
тоді:

```
python tools/make_palette.py     # Color.kt, colors.xml, CSS прототипу
python tools/check_contrast.py   # усі 4 схеми проти WCAG
```

`design/Color.kt` і `design/colors.xml` **видалені**: вони були не другою
думкою, а тими самими байтами, що й файли під `app/`. Дублікат означав, що
кожну зміну палітри треба робити двічі, а виглядало це зробленим після
першого разу.

Кольори жили в шести місцях, і наслідок був видимий: нічна схема існувала
лише в CSS прототипу, тобто Compose мав три схеми там, де дизайн має чотири, а
стан «відкладено» й три кольори підкладок не мали в Compose слота взагалі.
